## ✨ Sobre el proyecto

**Slack System** es un proyecto académico que implementa las principales funcionalidades de una plataforma de comunicación y colaboración inspirada en Slack.

Desarrollado en C++, busca aplicar conceptos fundamentales de programación, estructuras de datos, algoritmos y programación orientada a objetos mediante un sistema interactivo de consola.

## 🚀 Funcionalidades

- 👥 **Gestión de usuarios:** administración de usuarios y roles.
- 💬 **Canales:** creación y administración de espacios de comunicación.
- 📨 **Mensajería:** envío, edición y gestión de mensajes.
- 🧵 **Threads:** respuestas organizadas en conversaciones.
- 🔔 **Notificaciones:** gestión de notificaciones.
- 🤝 **Amigos:** funcionalidades de conexión entre usuarios.
- 📋 **Actividad:** seguimiento de interacciones.
- ↩️ **Edición:** control de modificaciones mediante estructuras de datos.

## 🧠 Conceptos aplicados

| Concepto | Aplicación |
|:---|:---|
| Programación Orientada a Objetos | Organización del sistema |
| Templates | Estructuras reutilizables |
| Recursividad | Resolución de operaciones |
| Lambda Expressions | Funciones y operaciones |
| Listas enlazadas | Gestión de información |
| Colas | Procesamiento de notificaciones |
| Pilas | Control de edición |
| QuickSort / MergeSort / HeapSort | Ordenamiento de mensajes |
