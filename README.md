## 💡 About

**Slack** es una implementación minimalista de una plataforma de mensajería colaborativa que permite gestionar usuarios, canales y conversaciones mediante un entorno interactivo de consola.

El proyecto busca representar las funcionalidades principales de Slack, aplicando programación orientada a objetos, programación genérica y estructuras de datos para gestionar eficientemente la información y las interacciones entre usuarios.

## ✨ Features

- 👥 **Users:** gestión de usuarios y roles.
- #️⃣ **Channels:** administración de canales de comunicación.
- 💬 **Messages:** envío, edición y organización de mensajes.
- 🧵 **Threads:** conversaciones y respuestas organizadas.
- 🔔 **Notifications:** gestión de notificaciones.
- 🤝 **Friends:** conexiones entre usuarios.
- 📊 **Activity:** seguimiento de actividad en canales.
- ↩️ **Message Editing:** historial y control de modificaciones.

## 🧠 Data Structures & Algorithms

| Structure / Algorithm | Application |
|:---|:---|
| Hash Table | Gestión de usuarios y canales |
| Balanced Binary Tree | Hilos de conversación |
| Graph | Menciones e interacciones |
| Doubly Linked List | Gestión de mensajes |
| Stack | Historial de ediciones |
| QuickSort | Ordenamiento de actividad de canales |
| Recursion | Procesamiento de hilos de conversación |
| File Handling | Almacenamiento del historial |
